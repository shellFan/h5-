## 一、修改前后对比

### 修改前
- `loadFromLevel` 把整波敌人(10~30只)塞进 pendingSpawns, 触发帧**一次性全部实例化** → 怪物瞬间贴脸
- 无场上上限、无批次间隔、无屏幕外预生成
- Boss 触发即出现在波点, 无预警
- 僵尸速度: 普通1.6 / 快速3.2(=2×普通, 屏幕感受过快)
- 单局时长 ~30 秒(总长150单位 ÷ 5速), 远低于 2-4 分钟目标

### 修改后 (GamePacingController, js/pacing.js)
| 参数 | 值 |
|---|---|
| waveTriggerAhead | 14 单位(≈2.8s 预见距离) |
| firstContactGrace | 0.5s(波激活观察窗口) |
| 批次间隔 | 0.8~1.5s 随机 |
| 批次规模 | 1~4 只(随关卡+1逼近上限) |
| maxAlive | 10+关卡索引, 封顶 20 |
| 生成点 | 队伍前方 11~20 单位(屏幕外预生成, 永远迎面涌入, 与队伍速度无关) |
| Boss 预警 | 提前 24 单位 → 横幅1.6s(震动+低鸣音效) → 出身点后退4(禁贴脸) + 弹性入场0.5s |
| 僵尸速度 | 普通1.7 / 快速2.55(=1.5×) / 盾1.15 / 精英1.0 / Boss0.9 |

## 二、关卡扩容 (dffde14)

- 中段(门+波)循环 ×3, 数量 1/1.7/2.6 递增, 段间距×1.5 → 单局 2-4 分钟
- 重复周期 mul 门降档(×3→×2, ×2→大额add)抑制人数通胀
- Boss 血量动态缩放: 基础表[500..3600] + 出场时队伍战力(dps×8), 四舍五入到50 → 任何养成水平 Boss 战 ≈8-12s + 狂暴阶段

## 三、节奏实测 (确定性引擎模拟, docs/V4_SIM_RESULTS.json)

- L1 第一波激活 ≈ 8.6s(触发43÷5速), 首批接触 ≈ 10s
- 波次间隔由段距(≈17×1.5=25单位≈5s)天然形成"战斗→走位→下一波"循环
- 关卡总时长: L1 ≈ 120s, L10 ≈ 147s; 0 步数封顶
- Boss 战: 动态血量下 left/greedy/balanced/random 均可完成(约 8-15s), 狂暴阶段造成人员消耗
