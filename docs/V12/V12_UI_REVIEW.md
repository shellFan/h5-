## 2. 明确不降级项（保持 H5 视觉语义）

- 24 个屏幕/面板全部经 minidom 渲染（无"文字按钮"化）
- 技能三选一为 3D 门机制（H5 同一实现，无独立弹窗）
- 战斗画面不被 UI 大面积遮挡：UI 层透明底 + 画布祖先不绘制背景 ✓

## 3. 已知视觉差异（小项，列入后续打磨）

1. 首页纵向排布与 H5 有小偏差（flex 交叉轴居中近似）—— 功能与可达性无影响；
2. inset box-shadow 以外阴影近似（按钮立体感略扁平）；
3. `backdrop-filter`/`filter: blur` 未支持（12 处毛玻璃装饰降级为半透明底）；
4. progress-flag 装饰旗为静态（transition 未插值）。

以上均为装饰级差异，无信息缺失、无交互障碍；不构成"临时占位效果"。

## 4. 溢出/遮挡/适配检查

- 横屏/矮屏 @media 条件按视口求值（8 档机型矩阵通过）✓
- 安全区：env(safe-area-inset-*) → wx safeArea 注入 ✓
