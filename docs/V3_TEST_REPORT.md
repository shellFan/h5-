## 关键修复验证记录(真实运行)

1. **道路虚空 Bug**: 射线探测证实重开后路段滞留 z≤-126; 无状态平铺修复后 750 步随机行走覆盖连续。
2. **Boss 击杀 Bug**: 直线弹道+±0.7命中窗 → 500人打不死200HP Boss(实测200/200不动); 瞄准收敛+窗口0.9/Boss1.4 → 120人8秒击杀+win结算。
3. **复活广告全流程**: 失败→按钮→TEST AD 模拟器→完整观看→复活(5人+无敌2.5s)→二次死亡按钮隐藏(计数器=1)。
4. **广告竞态**: 授奖回调竞态导致 E2E 1 例失败 → 计数器请求时消耗修复 → E2E 25/25。

## 测试基础设施

- tests/unit/run.js + suites/ (零依赖 Node 断言框架)
- tests/e2e/run.js (Playwright-core + 系统 Edge, 25 用例)
- tests/e2e/visual.js (4分辨率×8场景, 布局断言+截图存档)
- tests/e2e/perf.js (性能采样)
- test/sim.html + tools/sim-driver.js (确定性数值模拟)
- tools/gen-levels.js (10关配置生成器+自验证)

## 已知限制

1. E2E/视觉依赖系统 Edge 浏览器路径, CI 环境需预装。
2. 模拟器/测试用例不含音频断言(音效为 WebAudio 合成, 需真机听感验证)。
3. 视觉回归断言布局(裁切/遮挡/溢出), 不替代人工美术质量判断(见 V3_ART_REVIEW.md)。
