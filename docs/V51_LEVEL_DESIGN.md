## 阵地布局（wave.z 即防守锚点，队伍停于 z+9）
每关 4-5 个防守阵地，阵地间布置状态门排；L5 以三阶段 Boss 收尾（z=-150）。

### 第1关 新兵训练（4 波，44 怪）
1. 门 z-8：**全人数门**(+8/+5/+3) — 任何首选都成长，杜绝开局死
2. 波 z-18：普通×10
3. 门 z-28：+5 / 输出+1 / +8
4. 波 z-40：普通×12 + 快速×3
5. 门 z-52：射速+10% / +8 / 暴击+5%
6. 波 z-64：普通×10 + 快速×4；波 z-78：普通×5（收尾小潮）

### 第2关 快速尸潮（4 波，66 怪）
快速 10+14+12+6 搭配普通 8/8/6 与盾×2 引入；门含 人数+20% / ×2(首现) / 穿透。

### 第3关 盾牌军团（5 波，90 怪）
盾怪 8/12/10/6/6 主轴（各 10 HP 吸收弹幕），快速与远程伴随；门提供 输出+2 / 穿透 / ×2 / 冰冻。破防三路线：高伤、穿透、暴击。

### 第4关 变异尸潮（4 波，108 怪）
分裂 8/14/10/14/8 主轴（死亡分裂×2，考验溅射与穿透），远程 6→8，盾/快伴随；门引入 爆炸弹 / 连锁闪电 / ×2。

### 第5关 终局Boss（5 波 + Boss，127 怪）
精英×2 → ×3 阶梯出现；混合潮（分裂+远程+盾+快）构成 Boss 前减员压力；Boss「终焉核心」overlord：P1 普攻 → P2 召唤小怪 → P3 狂暴（移速/攻击提升）。

## 失败设计（不允许无解）
- 首排门全人数门 → 开局选择永不出死刑
- 状态门提供伤害/穿透/暴击/射速/人数多路线 → 至少两种升级流派可通关（模拟证明：greedy 5/5、left 3/5）
- 失败保留击杀金币（≤15）+ 首通奖励不重复 → 失败仍推进经济，可升级后再战
- 全类型 GLB、LOD、池化渲染支撑 60 场上上限不卡顿（见 V50/V51 性能文档）
