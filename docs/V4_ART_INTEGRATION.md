## 二、"蓝色球阵"根治 (本阶段核心)

**根因三连**:
1. 头盔球径 0.285 > 肩宽 0.2 → 背面视角只见蓝色圆顶
2. (V3.7 相机拉远后暴露) 肤色头球 0.26 > 缩小后的头盔 → "米色球海"
3. 相机不随人数缩放 → 密阵糊满屏幕

**修正**:
- 头盔 0.285→0.248, 头 0.26→0.225(藏进头盔), 五官/腮红/星标全部收拢到新球面
- 头盔后部白色竖条纹(背面识别条) + 背包加宽到0.28(背面主轮廓)
- **动态相机**: `updateCamera(x, z, dt, squadCount)` 按 sqrt(count/500) 平滑升高后移(6.1→8.7 / 7.8→10.0 / lookAhead -8.5→-10.5)
- 自适应阵型半宽≤2.3 + 行交错(保留V3.7)

## 六、验收返工记录 (V4.2-V4.4, 用户判定31人仍为球阵后)

**2026-11-12 用户验收结论: 31人场景仍为蓝色球阵 → V4.0美术验收不通过。** 前版自评("根治")有误, 以截图为准。

### 失败根因复盘 (对照390-squad-31.png)
1. 腿部几何被躯干胶囊吞没(躯干跨y0.17-0.79, 腿几乎全在内部) → 摆腿动画完全不可见
2. 头盔为光秃半球无帽檐 → 背后俯视=纯球体
3. 头盔0x2563EB与军服0x3B82F6色距过近 → 头身粘连成一坨蓝
4. 双臂全部前持枪 → 背面视角无任何手臂轮廓
5. 31人档9列×0.5过密 → 球体互相堆叠

### V4.2/4.3/4.4 返工内容 (tools/patch-soldier-v42/43/44.js)
- **帽檐裙边**(锥形裙边+深色包边环): 背后俯视呈椭圆环=明确"头盔"轮廓; 斜面无共面, 密阵相交不闪
- **躯干缩短上移**(len0.14)+**髋点0.34**+裤腿加长+靴子加大 → 腿部真实露出, 摆幅0.62→0.8
- **头盔深藏青0x1E3A8A** vs 亮蓝军服 → 头/身色块分离
- **亮蓝大肩甲**(±0.27, r0.105)超出帽檐宽度 → 背面剪影=深盔+亮蓝肩线
- **左臂改贴身摆臂姿**(跑步姿态背面可见)+白手套
- **背包白色X交叉背带**(大白色块, 经典士兵背面符号)+背包加大
- **顶饰天线+白绒球**(打破俯视球轮廓)
- 31-100人档改8列×0.58; 相机俯角下调(基线5.6/8.4, ~36°)

### 返工后验收(以截图为准)
- 31人: 每兵3重识别符号(深盔白绒球/白色X背带/亮蓝肩线+棕包), 8列4排错落 → **通过**
- 12人: 个体完整可辨(星标/腿/靴/摆臂) → 通过
- 500人: 深色军团+白色纹理点节奏, 边界不越界 → 通过
- 单人: 正面星标/眼睛/腮红完整, 背面剪影成立 → 通过
- 回归: 单测50/50 E2E 29/29 视觉32/32 全绿

**教训**: 美术验收必须以"逐人数档截图"为准, 不接受"模型有细节=画面达标"的推定; 俯视视角下人物可读性由剪影符号(帽檐/背带/肩线)决定, 与正面细节无关。
