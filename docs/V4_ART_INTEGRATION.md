## 二、"蓝色球阵"根治 (本阶段核心)

**根因三连**:
1. 头盔球径 0.285 > 肩宽 0.2 → 背面视角只见蓝色圆顶
2. (V3.7 相机拉远后暴露) 肤色头球 0.26 > 缩小后的头盔 → "米色球海"
3. 相机不随人数缩放 → 密阵糊满屏幕

**修正**:
- 头盔 0.285→0.248, 头 0.26→0.225(藏进头盔), 五官/腮红/星标全部收拢到新球面
- 头盔后部白色竖条纹(背面识别条) + 背包加宽到0.28(背面主轮廓)
- **动态相机**: `updateCamera(x, z, dt, squadCount)` 按 sqrt(count/500) 平滑升高后移(6.1→8.7 / 7.8→10.0 / lookAhead -8.5→-10.5)
- 自适应阵型半宽≤2.3 + 行交错(保留V3.7)
