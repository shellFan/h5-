## 3. 菜单与结算

- **开始界面**: Logo/标题渐变字/开始按钮/关卡选择10格(锁定灰/当前金)/提示文案 ✅
- **暂停菜单**: 继续/音效开关(V3.4)/重开/返回 ✅
- **胜利结算**: 星级/四格统计(剩余人数/击杀/最大连杀/时间)/下一关/**双倍奖励(金色,限1次)**/再来一次 ✅
- **失败结算**: 失败原因(V3.3)/统计/**观看广告复活(橙色,每局1次,次数用尽自动隐藏)**/重新挑战 ✅
- 面板在 360~1080 宽度均无裁切(视觉回归32项覆盖) ✅

## 5. 广告 UI 合规

- 复活按钮仅在 `canRevive()`(有次数+广告可用)时显示, 每局1次
- 双倍按钮领取后变"✓已领取"禁用, 新一局重置
- 刷门按钮右下悬浮+剩余次数角标, 无可刷门时自动隐藏
- 广告期间: 游戏逻辑暂停, TEST AD 模拟器明确标注"测试广告"字样
- 不支持广告的平台: 三入口全部隐藏, 游戏流程不受影响

## 6. 遗留 UI 差距(诚实记录)

1. 设置界面为"暂停菜单内音效开关"简版, 未做独立设置页(画质切换暂为自动检测)
2. 无金币/奖励持久化经济系统, "双倍奖励"作用于当局结算展示(经济系统为后续版本任务)
3. 抖音端 UI(HTML层)整体缺失, 依赖小游戏原生UI重做 — 未实施(阻塞于开发者工具验证)
