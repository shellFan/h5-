## 三、已知的非阻塞问题

1. balanced/random 模拟策略在 L2-L4 有失败路线(策略僵化所致, greedy/left 全通) — 玩家可选路线存在
2. E2E 在 SwiftShader 下偶发渲染超时(重跑即绿, 未定位为代码问题)
3. 大人数(500)顶棚时人数增长无张力(数值已用 mul 降档缓解)
4. 程序化模型无骨骼动画 — 表现力上限(如需更进一步, 引入 GLB+Blender)
