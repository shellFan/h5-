# V13 · 素材管线规范 (ASSET_PIPELINE)

> 目的: 定义《膨胀小队》从「需求 → 制作 → 检查 → 登记 → 接入 → 验收」的标准素材流水线。
> 任何后续 Agent/开发者新增视觉素材, 必须走本管线, 并在 docs/V13/ASSET_MANIFEST.md 登记。

## 1. 素材来源优先级

1. **现有项目资源**(assets/ 与程序化生成) — 先对账, 不重复制作;
2. **原创程序化生成**(Canvas 纹理 / 内联 SVG / 几何构建 — 本项目主力方式, 零加载开销);
3. **合法授权素材**(需在 ASSET_LICENSES.md 登记来源与许可);
4. 禁止: 网络随意图片 / 未授权商业素材 / 其他游戏受保护素材 / 风格不符的随机 AI 图。

## 2. 制作规范(按类型)

### 2.1 3D 模型 (GLB)
- 工具: Blender 导出 glTF 2.0 binary;
- 自包含: 贴图内嵌(basecolor + ORM 共享), **禁止外部纹理 URI**(微信包内读文件受限);
- 材质: MeshStandardMaterial 语义; 项目渲染侧经 `preparePbr` 注入 LinearTosRGB 显示变换
  (色彩工作流见 docs/art/ART_DIRECTION.md §2, 禁全局 sRGBEncoding);
- 面数纪律: 角色 hero ≤ 15k / lod ≤ 5k; 环境 ≤ 2k/件;
- 命名: `assets/models/<类别>/<名称>/<名称>[-lod].glb`(lod 后缀), 配 `model-stats.json`(面数/尺寸);
- 刚体部件约定: Body/Head/Arms/LegL/LegR + Muzzle(士兵), 与 InstancedMesh bank 管线对齐;
- 动画: 项目为程序化姿态驱动(非骨骼动画), GLB 不需内嵌动画轨。

### 2.2 程序化纹理 (CanvasTexture)
- 尺寸 2 的幂优先; 单张 Canvas 单次绘制, `needsUpdate` 仅在重绘时置位;
- 色彩必须使用 ART_DIRECTION 色板契约; 透明通道仅确需时启用(depthWrite 策略随之声明);
- 引用缓存: 同参数纹理必须复用(如门玻璃按稀有度缓存), 禁止逐实例重绘。

### 2.3 SVG 图标
- viewBox 固定(图标 64×38 / 24×24), 手写 path, 轮廓优先(0.3s 可辨);
- 色值来自设计系统令牌; 内联交付(零二进制、零请求);
- 接入方式: ui-v60 生成器函数(参考 `weaponIconSvg`)。

### 2.4 CSS 视觉层
- 新层以版本号文件追加(style-v1NN.css), **不修改前层规则**;
- 只用既有设计令牌(--v12-*/--v13-*), 新令牌须在本层 :root 定义并写入 UI_DESIGN_SYSTEM;
- 动效只用令牌时长/缓动; 必须带 prefers-reduced-motion 与游戏内减少动效降级。

## 3. 质量检查清单(接入前逐项)

| 类型 | 检查项 |
|---|---|
| 图片/SVG | 尺寸正确 / 透明边缘无白边 / 色值在色板内 / 无拉伸 / 文件完整 |
| GLB | 可解析 / 贴图内嵌 / 材质完整 / UV 无接缝错误 / 面数达标 / 尺寸符合比例契约 |
| CSS | 无前层覆盖冲突 / 令牌化 / reduced-motion 降级存在 |
| 通用 | 命名规范 / 路径规范 / 与现有素材风格统一(样板对照) |

## 4. 登记制度

接入后 24h 内在 docs/V13/ASSET_MANIFEST.md 追加行:
名称 / 类型 / 用途 / 路径 / 尺寸 / 格式 / 大小 / 来源 / 许可 / 接入位置 / 验收状态(截图)。

## 5. 接入与验收闭环

素材完成的定义 = 文件生成 → 检查 → 命名归档 → **代码引用** → **真实运行** → 截图 → 性能复核 → 登记。
只生成不接入 = 未完成。无法接入(缺业务事件/需核心改动)必须如实记录, 不得伪造。
