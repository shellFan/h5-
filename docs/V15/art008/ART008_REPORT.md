   - 彻底告别单调模糊几何体背景，独立生成并接入三套与首页完全同源的高精度 3D 玩具军事卡通竖屏室内场景：

2. **士兵训练中心彻底重做（`58 → 目标 90/100`，`js/ui-v60.js` + `style-art-military.css`）**
   - 独立顶栏（`‹ 返回` | `BARRACKS 士兵训练中心` | 实时金币徽章），清除顶部多余标题与半屏空背包占位。
   - **中央大型英雄展示台 + 左右 6 个独立战术装备槽**：头盔、防弹衣、主武器、背包、战术装备、军团徽章，每槽配专属战术轮廓 SVG 图标与品质发光边框，彻底消除「未装备 空」文字表格感。
   - **3×2 紧凑图标化属性网格**：伤害加成、生命加成、暴击率、伤害减免、招募效率、军团军衔一目了然。
   - **单行紧凑背包栏 + 底部醒目升级按钮**（`强化升级 Lv.1 → Lv.2 · 金币 50`），彻底告别后台管理页观感。
3. **武器军械库第二次重构（`71 → 目标 90/100`，`js/ui-v60.js` + `style-art-military.css`）**
   - 取消首页上方大弹窗与底部重复卡片；中央大尺寸武器展示台（`224×196`）直对拉丝钢聚光台，展示武器名称、等级、当前属性、下一级属性预览，并将「强化升级 / 进化」集中至固定操作区。
   - 底部重构为 **4×2 紧凑武器缩略图选择栏**：一屏完整展示全部 8 把武器（含装备中金标与解锁关卡徽章），零截断、零冗余返回键、零重复卡片。
4. **升级商店场景与视觉深化（`77 → 目标 88/100`）**
   - 接入独立 3D 后勤补给帐篷背景（木架、营灯、军包与金币宝箱），保留独立 3D 图标、等级徽章、绿金进度条、升级前后数值对比及深军绿铜金描边不可购买按钮。
