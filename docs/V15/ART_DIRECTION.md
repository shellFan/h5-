# 《膨胀小队》V15.0 美术方向与工程规范 (ART DIRECTION)

## 1. 最高优先级视觉标准
- **核心风格**：`Premium Stylized 3D Toy Military Cartoon`（高品质 3D 卡通玩具军事风格）
- **视觉基准**：ChatGPT V15 竖屏阳光军事基地战斗设计稿（军绿色玩具士兵小队、三跑道混凝土主路、立体发光增益门 + 地面引导箭头、紫色卡通怪兽潮与巨型 Boss、阳光军事基地要塞与远景蓝天白云、极简高对比军工 HUD）。
- **严格禁止**：回退至蓝紫色赛博朋克、廉价科技风、扁平网页卡片式 HUD、整图概念稿贴作静态背景、2D 士兵图替代 3D 骨骼/分体模型。

## 2. 色彩与材质体系
| 元素 | 主色系 | 材质与质感要求 |
|---|---|---|
| 阳光天空与远景 | 天蓝 `#2E8BE8` → 晴空 `#78C4FA` → 地平暖白 `#E6F4FF` | 渐变穹顶 + 立体白云群，雾效远推至 52~135m，保持中景通透 |
| 混凝土三跑道 | 军工中灰 `#7E868C` + 亮白虚线 `#F8FAF5` + 暖黄边线 `#F2C94C` | 粗糙混凝土质感 + 轮胎压痕 + 伸缩缝，提供高对比度衬托士兵与子弹 |
| 军绿士兵与装备 | 橄榄军绿 `#4B6E38` / `#5F8745` + 暖沙战术包 + 金属枪械 | 卡通塑料/烤漆金属质感，高光柔和，脚底清晰投影 |
| 军事基地道具 | 橄榄帆布帐篷、迷彩坦克、木质瞭望塔、黄黑防撞墩、红星战旗 | 低面数 InstancedMesh 复用，零每帧分配 |
| 紫色怪兽与 Boss | 饱和紫 `#7A38C8` + 暗甲 `#3C2B4D` + 亮眼/利齿 | 体积饱满、与灰白路面和绿色士兵形成鲜明色相分离 |
| 三跑道增益门 | 绿(增援 `#22D46B`) / 蓝(火力 `#2596FF`) / 金(金币/特殊 `#FFB726`) / 紫(倍增 `#A84DFF`) / 红(高危 `#F04452`) | 厚重金属倒角门框 + 黄黑警示底座 + 顶部指示灯 + 发光能量玻璃 + 立体图标 + 地面动态三连箭头 |
| 战斗 HUD | 深军绿钢化边框 `#1E3726` / `#3E6345` + 金橙点缀 `#FFD24C` | 单排精简顶栏（左上暂停、中上关卡与绿条进度、右上金币与人数），禁止蓝紫旧样式残留 |

## 3. 资产命名与目录规范
- 现有结构保持稳定，不盲目迁移：
  - `assets/game/models/`：运行时 GLB（士兵、僵尸、Boss、武器，含 hero + lod）
  - `assets/game/ui/`、`assets/game/characters/`、`assets/game/weapons/`、`assets/game/maps/`：已处理运行期 UI 与图标资产
  - `docs/V15/`：V15 美术工程文档、资产清单及改造前后真实运行截图
- 所有新增资产必须声明明确运行时用途，严禁无目的地批量生成图片。
