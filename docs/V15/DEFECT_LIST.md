### DEF-1: 关卡地图页节点溢出遮挡返回按钮(P1·可交互性)
- **复现**: 打开 关卡地图 → 滚动到列表底部(10/10 节点) → 点击"返回"
- **预期**: 返回首页
- **实际(修复前)**: 第 10 关节点的 meta 行(威胁/奖励文本)溢出列表容器,
  与返回按钮重叠并拦截点击(playwright 11 次重试失败)
- **几何实证**: 修复前 node-meta y788-802 与 back y773-817 重叠
- **根因**: `#game-container.v42-ui .v60-page .v60-panel .v60-map-nodes` 规则
  设置了 flex 限高但 **遗漏 `overflow-y: auto`** — 内容溢出可见且参与命中测试
- **修复**: style-v60.css 补 `overflow-y: auto`(与 ach-list/codex-list 同组规则)
- **修复后测试**: map-rect 几何复测(列表底 777 < back 顶 787 ✓) +
  map-click-test.js 真实点击 打开→关闭 全通过 ✓
- **影响范围**: 关卡地图页(全部视口, 手机端尤甚)

### DEF-2: 启动加载屏完成态回退闪动 + 隐藏时序竞态(P2·视觉/测试稳定性)
- **现象**: 进度条到 100%"准备完毕!"后, 后台续载的进度事件把百分比回写成
  "加载中 n/26"(视觉回退闪动); 且加载屏在游戏可玩后仍滞留 260ms。
- **根因**: `__BootProgress.done()` 无闩锁(后台 file() 事件持续回写 UI) +
  隐藏走 260ms setTimeout(竞态窗口)。
- **修复**: done() 加 `_done` 闩锁(file() 完成后早退) + 就绪即隐藏
  (bar 宽度 .18s 过渡保留动画感)。
- **修复后测试**: vnext-rank"加载完成100%后隐藏"断言 **4 连跑 16/16**(修复前
  1/3 失败) + 核心全套件复跑全绿 + 微信模拟器 20/20。
- **影响范围**: 所有平台的启动加载体验 + vnext-rank 测试稳定性。
