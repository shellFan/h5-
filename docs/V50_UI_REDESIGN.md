## V5.0 修复的 UI 缺陷
1. 首页品牌角标版本号过期（V42）
2. 首页缺音效开关/最高纪录（任务书 9.1 要求项）
3. 首页待机士兵被面板遮挡，无军团展示感
4. 失败页缺返回首页入口（任务书 9.5 要求项）
5. 胜利页三星在截图中"只显示 1 颗"——定位为弹出动画时序（截图过早），游戏内正常
6. 门文字被亮色玻璃与远景雾洗白（label 移至玻璃前 + fog:false + 背板加深）
