## 2. 修复问题清单（含证据）
1. **movement.js** 灵敏度语义反直觉 → 直观语义（越大越快），1.0=满屏横穿；单测+e2e 同步更新（用户历史反馈"移动太快"同步解决：等效降速 35%）
2. **DouyinAdService.tt 未接线** → 广告初始化必抛错 → 已修复并接 Platform 门面
3. **showRewarded 无超时** → 平台回调丢失永久暂停 → 30s 超时结算 failed
4. **广告位配置链失效** → game-config.js 注入变量被源码覆盖 → 改为 `window.__GAME_SETTINGS` 读取
5. **H5 生产直接用 Mock 广告发真实奖励** → 仅 localhost/显式 ?adtest 装配；生产如实降级
6. **抖音构建四重缺陷**（缺 game.js/THREE 未加载/require 路径错/CommonJS 作用域）→ 单文件 bundle 重写 + 分包 + 自检
7. **抖音端无声** → tt.createInnerAudioContext + 运行时 WAV 合成
8. **hide 时音频不停** → lifecycle hide → audio.suspend；blur/focus 兜底由死代码改为真实实现
9. **首排门选 buff 即死**（平衡模拟证据）→ 首排全人数门
10. **L3 Boss 竞速弱 build 必败** → 击杀 3→2 + 血量系数 8→7s
11. **boss-name 节点空引用**（非 index 页面崩溃）→ 防御判空
12. **模拟工装 rAF 干扰** → 模拟期 paused 隔离（遗留工装级非密闭性，见平衡文档）
