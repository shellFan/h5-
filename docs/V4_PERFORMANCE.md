## 二、V4 渲染成本控制

- 士兵: 3×InstancedMesh(身体/左右腿) 单次绘制调用渲染全军(500容量), 每帧仅矩阵更新
- 僵尸: 合并批处理 2mesh/只 共享 2 材质(V3.5保留)
- 弹道: Sprite 池 120 上限; 粒子池 120-300 按画质
- 阴影: q≥1 开启, 阴影相机随小队移动
- 动态相机/慢动作不增加渲染成本(仅矩阵/时间缩放)

## 三、泄漏修复对性能的连带收益

浸泡测试定位的共享几何误 dispose 修复(9b24d6f)同时消除了"每只僵尸死亡→全批合并几何 GPU 重传"的隐性开销 — 中后期高击杀场景的帧稳定性直接受益。
