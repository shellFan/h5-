## 3. 实测发现的问题 (全部来自真实运行截图)

基线截图: tests/screenshots/baseline-v22/

### P0 (阻塞视觉验收)

1. **重开后道路消失 — 大面积浅蓝空白的第一根因**
   - world.js `updateRoadScroll` 只做 `z -= SEG_LEN * 12` 向后跳跃回收; 游戏重开(squad.reset z=0)后 12 段路面全部滞留在 z≤-126, 玩家从 0 一路踩空到约 -156。
   - 射线探测证实: 屏幕下半 45% 命中 NONE(背景/雾色), 见 07_void_road_1080.png。
   - 首次加载时路段初始 12..-120, 第一局勉强覆盖; 任何重开/复活/失败重试后道路必消失。
2. **整屏过曝发白**
   - 灯光强度合计 ≈1.85 (hemi 0.75 + dir 0.85 + fill 0.25), Lambert 材质 × 1.85 后全部钳制到白;
   - fog(0xB8D8F0, 30, 80) 雾色极浅, 距离稍远即被雾色吞掉;
   - 无色调映射 (NoToneMapping), outputEncoding=sRGB 使 hex 颜色再次提亮。
3. **士兵可辨识度低**: 500 人时是蓝色球体海洋, 头盔星徽/背包/枪械几乎不可辨 (04/05 截图)。
4. **Boss 视觉失败**: 过曝后成白色圆球, 角/肩甲细节全无 (05 截图)。
5. **弹道不可见/命中差**: 子弹 x 固定直线飞行, 命中窗口 ±0.7, 阵型散布 ±1.56 → 约 5/7 子弹永远打不中单点目标; Boss 战 DPS 实测仅为理论值一小部分 (combat.js:137)。
6. **Boss 血条与左侧属性面板重叠** (05 截图)。

### P1

7. 状态门玻璃过曝发白, 远处多排门同时可见造成视觉杂讯 (06)。
8. 环境装饰(树/建筑/车)被过曝+雾吞掉, 远景层次缺失 (07 中建筑仅剩剪影)。

- IAB 面板失焦时 rAF 停摆, 游戏逻辑冻结 → 视觉测试必须用"手动步进 + 强制相机收敛"驱动, 不能依赖真实时间流逝。V3.5 将内置确定性测试驱动 (window.__test.tick)。
