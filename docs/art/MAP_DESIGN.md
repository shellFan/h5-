# 地图与场景设计规范 (MAP_DESIGN)

> 实现: `js/world.js`(道路/草地/天空/灯光/滚动) + `js/art-v42.js buildEnvironment`(城市装饰)。
> 玩法约束: 三车道(LANE_WIDTH 2.0 × 3, 路面 6.8 宽)与关卡布局为业务锁定, 视觉层不得改变碰撞面。

## 1. 场景分层 (由近及远)

| 层 | 内容 | 实现 |
|---|---|---|
| 天空 | 渐变穹顶(BackSide 球 r=88, 跟随相机 XZ) + 顶部光晕 | `_buildSky`, renderOrder -10 |
| 远景 | 天际线剪影(远排建筑) | `addStreetDetails` |
| 中景 | 双向建筑群(3 色系+屋顶饰+窗+店面)、行道树、路灯、车、锥桶、护栏 | InstancedMesh 分类 |
| 战斗层 | 道路 12 段滚动(柏油纹理) + 人行道 + 路缘 + 起点斑马线 | `_buildRoad` |
| 地表 | 草地 20u 宽×两侧, V12 修剪条纹+淡草斑 | 顶点色合并 |
| 氛围 | 云(12 朵折返循环) + 雾(45→130) | |

## 2. 道路纹理规范 (256×512 CanvasTexture, 12 段循环)

- 底色 #7C8B96 + 4 条宽幅淡色带(打破整段同色) + 400 粒噪点 + 8 条细裂缝。
- 车辙两条 rgba(28,40,48,.10); 修补椭圆 ×5。
- 车道虚线 #F0EEF5(对齐 X=±1 车道边界); drain 盖左右各一。
- **路缘警示线(V12)**: 暗衬边 rgba(52,58,48,.35) + #E3C26B 主体 — 饱和度降档, 不再与金币/UI 金抢注意力。

## 3. 主题换装 (applyTheme)

- default: 渐变穹顶原色, 雾 0xC9E4F2。
- apocalypse(L6 末日核心): 穹顶乘色 0x8A5060, 雾/灯光/实例染色走 CONFIG.APOCALYPSE_THEME。
- 新主题 = 新 THEME 对象 + applyTheme 分支; 禁止硬编码在装饰生成器里。

## 4. 滚动与循环 (锁定算法)

- 无状态平铺: `updateRoadScroll(squadZ)` 直接计算每段归属(重开/复活/传送自动正确)。
- 装饰/建筑窗口 [squadZ-170, +20], 云窗口 110 — 折返不闪烁。
- 任何视觉增补必须保持该算法(不允许在 update 里做逐帧重排)。

## 5. 战斗区域辨识度

- 战斗区(路面 6.8u)与装饰区(草地/人行道)以路缘+护栏双线分隔, 颜色对比保持 ≥1.4:1。
- 状态门/精英光环/decal 均 renderOrder≥1 且 depthWrite false, 压在地表之上不压在角色之下。
- 光影: 唯一投影源=太阳方向光; 阴影视锥 ±8×(12,-12) 随队移动 — 新增大件装饰必须落在视锥内或放弃投影。

## 6. 变更守则

- 装饰密度: 每类 InstancedMesh 上限以 `docs/v11_perf_final.json` 基线为准, 新增分类必须给出 drawCall 预算。
- 纹理一律 CanvasTexture 程序化生成; 引入外部贴图需先登记 `ASSET_MANIFEST.md` + 授权。
