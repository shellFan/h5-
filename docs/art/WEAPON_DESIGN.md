# 武器与弹道设计规范 (WEAPON_DESIGN)

> 数据/平衡: `js/weapons.js`(8 武器, 业务锁定) + `js/combat.js`(弹道视觉) + `js/soldier-loader.js`(枪口)。
> 本规范只约束**表现层**; 伤害/射速/进化数值不得在此层面变更。

## 1. 武器阵容 (8 种, 视觉=士兵 GLB 统一枪模 + 弹道差异化)

| 武器 | 弹道表现 | 命中特征 |
|---|---|---|
| 标准步枪 | 金色曳光(0.26×2.1) | 黄星闪 |
| 散弹枪 | pellets 扇形多发曳光 | 多点黄星 |
| 狙击枪 | 单发长曳光(高伤害口径) | 白星+高飘字 |
| 机枪 | 高频短曳光(visualRate 上限 30/s) | 密集黄星 |
| 火焰喷射器 | 曳光+命中橙粒子 | 橙星+燃烧 DoT 粒子 |
| 火箭炮 | 曳光+爆炸弹溅射(白闪 flash 1.5) | 橙星+溅射 |
| 电链类 | 曳光+跳链蓝粒子(0x66D9FF) | 蓝星逐跳 |
| 毒液类 | 曳光+毒绿粒子(0x88CC44) | 绿星+毒 DoT |

## 2. 曳光弹规范 (V12)

- 贴图: 程序化 64×256 Canvas(白热弹头椭圆核 + 锥形双层尾迹渐隐), `combat.js _makeTracerTexture`。
- 朝向: 贴地掠过 — 平面 rotX(-90°+24°), 弹头朝 -Z, 尾部微抬向镜头; 暴击弹 0.34×2.8, 普通 0.26×2.1。
- 颜色: 材质 0xFFD700 × 贴图; Normal 混合(Additive 在浅路面会加成纯白, V3.6 教训)。
- 尺寸变化=信息: 暴击更粗更长; 新武器若需识别色, 走"材质 color × 现有贴图"方案, 不新增贴图。

## 3. 枪口火焰

- 4 角星 + 中心径向亮核(64×64 Canvas), 生命 0.07s, 上限 24, V12 随机滚转(π)×尺度抖动(0.42-0.52)。
- 位置: GLB Muzzle 权威(`soldier-loader.js` muzzleMatrix)。

## 4. 命中反馈链

```
命中: 星闪(0.16s, 大小=致命>暴击>普通, 颜色随武器)
  ├─ 粒子爆 3-6 颗(0.25s)
  ├─ 伤害飘字: 12% 概率 / 暴击必显(白芯描边)
  └─ DoT: 燃烧橙 / 毒绿 / 冰冻蓝 粒子标记
击杀: cfg 色粒子爆 12 + 白闪 4 + 金色积分点 3 + 尸液 decal(2.2s)
```

## 5. 变更守则

- 弹道上限 `BULLET_MAX_VISIBLE=120` 锁定; 新视觉通道必须走池化并声明预算。
- 禁止为武器增加独立枪械模型(破坏 InstancedMesh 批渲染) — 武器识别靠弹道/命中色与 UI 军械库。
