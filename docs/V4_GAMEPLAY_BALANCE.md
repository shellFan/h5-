## 二、确定性数值模拟 (5策略×10关, 真实引擎驱动)

工具: `node tools/run-sim.js`(LCG固定种子, DT=0.033步进 `_updateInner`)

| 策略 | 通关 | 均时 | 说明 |
|---|---|---|---|
| greedy(贪心) | **10/10** | 135s | 主线: 乘法门优先 |
| left(人数流) | **10/10** | 135s | 均选左门 |
| balanced(均衡) | 7/10 | 134s | L2/L3/L4 失败 — 策略僵化(固定轮换), 非数值死局 |
| random(随机) | 8/10 | 109s | L3/L7 偶败 |
| right(最差路线) | 1/10 | 34s | 均选右门(buff线无成长) — 符合"坏策略应失败"设计 |

- **≥2 条可行通关路线**: ✓ greedy + left 全通
- **单局 2-4 分钟**: ✓ L1≈120s, L10≈147s, 0 步数封顶
- L10: 147s / 650 击杀 / 500 人满编
- 明细: docs/V4_SIM_RESULTS.json

## 三、失败曲线

- right 策略开局 6-15s 全灭(max=1) — 门选择错误的惩罚真实存在
- balanced 早期关卡失败提示"输出流起步过慢被前期怪潮消耗" — 玩家学习曲线的一部分
