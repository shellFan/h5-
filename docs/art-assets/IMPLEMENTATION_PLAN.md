## 分阶段交付

1. **来源入库**：Python/Pillow 可重复导入器；86 份字节未改变的 JPG；90 条 JSON/CSV 清单；重复组和来源说明。原图目录禁止运行时打包。
2. **资源处理**：86 份压缩 WebP 审阅副本；逐图复核的裁剪配方、透明边缘预览、图集元数据、资源映射。仅无文字可用区域进入游戏 UI；完整概念图仅作为明确标识的图鉴资料，不冒充战斗资源。
3. **界面接入**：明亮军绿色/暖金主题，头像、图标、菜单、HUD、升级、军械库、商店、排行、胜负、暂停、设置实际交互。文字数字保持代码绘制。以现有经济与存档显示真实值。
4. **战斗接入**：保留现有模型结构与动画，士兵绿色材质变体、彩色怪物、机械 Boss 兼容表现；五种基地场景使用背景/中景/道路/前景模块循环，装饰不占跑道；抽取特效使用数量上限和复用。新枪械外观映射已有武器业务类型，不虚构十种新业务逻辑。
5. **跨平台构建**：H5/微信/抖音明确排除 art-source；微信按需加载美术分包并检查预算、图片路径、降级。旧资源保留，可由 Git 单阶段回滚。
6. **验收**：清单和原图哈希校验、图像尺寸/透明度检查、构建检查、玩法回归、320/360/375/390/414/430 宽度截图、Boss/胜负/重试/门/奖励/商店/排行、H5 与微信模拟器真实启动。基线与最终同环境测量首屏、包体、FPS、内存和 Draw Calls；桌面模拟不冒充真机。
7. **推送核验**：每阶段独立 commit，普通 push 指定分支；读取远程分支和树，抽查二进制 SHA256。原 ZIP 留在本地，不重复上传整包。
