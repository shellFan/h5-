1. **Boss 造型辨识**(审计发现 hivelord/titan 实机同形同色): 新增 BOSS_PRESENTATION
   表 — 每型专属染色(hivelord 毒绿/titan 岩灰/overlord 紫黑/bulwark 钢蓝/spitking
   酸黄) + 体态缩放(胀腹/宽矮厚重) + 程序化附件(hivelord 背囊×3 呼吸脉动 /
   overlord 双角 / titan 肩甲) + 入场特效按型配色。**审计同时揪出真实缺陷**: Boss GLB
   后台续载未就绪时以 normal 模型渲染(绿僵尸假象) — 探针修正为等待就绪后复审。
2. **僵尸体型 Rig**: 新增 BODY_RIGS 侧影家族(standard/brute/huncher/wiry), 变体
   从"只有颜色不同"升级为骨架姿态差(壮硕大臂/驼背前倾/瘦长高个), 与染色/附件正交叠加。
3. **武器 GLB 重设计**: 双材质→三材质(+每型身份色配件, 与弹道色呼应: 步枪海军蓝/

   (加宽机匣/加粗枪管/管口环), 部件材质语义归位(握托=聚合物, 身份件=配件色)。
4. **展示台机位**: 三轮截图迭代定稿 45° 俯侧视角。
5. **地图密度**: 城市路侧 54→76 / 建筑 44→50 / 城市跨街横幅(高空峡谷感) /
