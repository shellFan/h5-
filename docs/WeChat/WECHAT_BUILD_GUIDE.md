# 微信小游戏构建与上线指南 (V12)

## 1. 构建

```bash
node tools/build-wechat.js
```

产物输出到 **`wechat-game/`**（可直接导入微信开发者工具）。构建包含自检：
bundle 段完整性、关键类、UI 树、P0 资源、包体预算（主包<4MB / 分包<4MB / 整包<30MB），
任一失败即报错退出。

## 2. 本地验证（无需真实 AppID）

### 2.1 自动化模拟器（已内置）

```bash
node tests/e2e/wechat-emulator.js
```

浏览器内 wx 模拟层加载真实构建产物，跑 17 项冒烟断言并输出截图到
`docs/WeChat/screenshots/`。这是**构建产物级验证**，不等同开发者工具验证。

### 2.2 微信开发者工具

1. 打开微信开发者工具 → 导入项目 → 目录选择 `wechat-game/`；
2. AppID 选择「测试号」（或点击"使用测试号"）；
3. 编译 → 模拟器应显示首页（蓝色科技风、膨胀小队标题、部署小队按钮）；
4. 按下方验收清单逐项过一遍。

## 3. 上线前必填配置

| 文件 | 字段 | 说明 |
|---|---|---|
| `wechat-game/project.config.json` | `appid` | 微信公众平台注册的小游戏 AppID |
| `wechat-game/game-config.js` | `ads.wechat.rewardVideo` | 流量主后台的激励视频广告位 ID；留空则广告如实不可用 |

> 合规：不要提交 AppSecret/支付密钥到仓库；正式广告位 ID 仅在上线配置中填写。

## 4. 发布流程（微信公众平台）

1. 开发者工具右上角「上传」，填写版本号（如 1.0.0）与项目备注；
2. 公众平台 → 版本管理 → 提交审核（首次需类目/资质）；
3. 审核通过后发布。

## 5. 常见问题

| 现象 | 处理 |
|---|---|
| 首页白屏 | 看控制台是否 GLB 读取失败：检查 assets 分包是否完整上传 |
| 无声音 | 音频需用户手势触发后初始化（点任意按钮即激活） |
| 广告按钮不出现 | 未配置广告位 ID 时如实降级（按钮自动隐藏），上线前填入即恢复 |
| 存档丢失 | V12 已有 .bak 双写回退；若双份损坏会保留 `.corrupt` 现场键供诊断 |
| 包体超限 | 检查 assets-manifest.json，勿把源纹理/文档打进包（构建已排除） |

## 6. 与抖音端的关系

`tools/build-douyin.js` 与本脚本同构（单作用域 bundle + 环境模拟层 + 分包）。
V12 已修复抖音构建的三个历史缺陷：GAME_SCRIPTS 缺 js/game.js（P0）、
自检假阳性、入口漏载 game-config。双端共用同一份游戏源码与平台适配层。
