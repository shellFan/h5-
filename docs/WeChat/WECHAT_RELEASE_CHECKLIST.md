# 微信小游戏 V1.0 发布前人工清单 (V12)

> 自动化已覆盖的部分见 WECHAT_TEST_REPORT.md；本清单是**无法自动化、必须人工执行**的
> 发布门槛。逐项打勾后方可提审。

## 0. 前置条件

- [ ] 微信开发者工具（稳定版）已安装
- [ ] 小游戏 AppID 已注册（或在工具内使用测试号先行验证）
- [ ] 已执行 `node tools/build-wechat.js`，自检全绿

## 1. 工具内验证

- [ ] 导入 `wechat-game/` 目录，编译无报错
- [ ] 首页完整渲染（标题/部署按钮/关卡选择/设置入口）
- [ ] 开始游戏 → 3D 场景出现，士兵/僵尸模型加载正常
- [ ] 完整通关第 1 关（状态门三选一 / 技能生效 / Boss / 胜利结算）
- [ ] 失败一次（失败结算 + 复活按钮按广告配置决定显隐）
- [ ] 暂停/恢复；返回主菜单
- [ ] 军械库 / 士兵成长 / 装备 / 科技树 / 成就 / 每日任务 / 设置 页面可开可回
- [ ] 画质设置切换（提示重启后生效）
- [ ] 存档：金币消费后退出小程序重进，数据保留
- [ ] 切后台 → 回到微信 → 再进入：战斗处于暂停态，恢复后正常
- [ ] 分包：调试器 → 代码依赖分析，assets 分包完整、无主包越界

## 2. 真机预览（至少 iOS + Android 各一台）

- [ ] 首屏加载 ≤ 5s（中端机）
- [ ] 战斗帧率：高端机 ≈60fps / 中端机 ≥30fps / 低端机流畅（可降画质）
- [ ] 触控跟手（拖动换跑道、技能按钮、弹窗）
- [ ] 音效有声（首次点击后）、静音开关持久化
- [ ] 长时间游玩（10 分钟）无明显发热降频导致的卡顿
- [ ] 切后台/来电中断恢复正常
- [ ] 异常断网重试模型加载不卡死

## 3. 商业化（需要真实广告位 ID）

- [ ] `game-config.js` 填入激励视频广告位 ID
- [ ] 完整观看 → 奖励发放且只发一次（重复点开/重进不再发放）
- [ ] 中途关闭 → 不发奖
- [ ] 广告加载失败 → 按钮降级/提示，不阻塞游戏
- [ ] 每局频控：复活 1 次 / 双倍 1 次 / 刷门 2 次
- [ ] 复核《微信小游戏广告合规》：激励视频由用户主动触发、奖励与观看完成绑定

## 4. 提审前

- [ ] `project.config.json` 填正式 AppID
- [ ] 版本号/项目备注填写
- [ ] 隐私协议/用户协议链接有效（如平台要求）
- [ ] 上传 → 提交审核

## 5. 已知未覆盖项（如实记录）

- 真机上的 GPU 内存/发热长期曲线（需真机才能测）
- 好友排行榜开放数据域（V1.0 为本地排行榜，开放数据域列入后续版本）
- 分享卡片图（当前使用默认截图，可后续配置 imageUrl）
