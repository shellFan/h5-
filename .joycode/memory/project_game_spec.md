《膨胀小队》: Count Masters式人数膨胀(70%) + Last War式自动射击(30%)的3D卡通休闲手游。

**Why:** 用户提供了详细的8模块美术方向规范，核心体验是"人数膨胀爽感+自动射击清怪"。

**How to apply:**
- 性能硬约束: 1→500人用InstancedMesh单次DrawCall，弹道上限120，粒子池300
- 技术栈: 纯前端Three.js r149 CDN加载，无构建工具，Node.js不可用
- 视觉: 9:16竖屏、蓝色Q版士兵、6种僵尸、半透明玻璃状态门、金黄弹道
- 交付顺序: 先高品质画面 → 第一关可玩 → 验收 → 扩展10关
- 禁止占位符美术，所有模型用几何体组合+顶点色实现
