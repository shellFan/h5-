# Spitter V42 model

Original cartoon enemy generated by Blender 4.2.15 from `tools/create-enemies.py` and
`tools/blender_art_common.py`; no downloaded reference mesh was available or used.

Generate the complete family from the repository root:

```powershell
& 'D:/tools/blender-v41/blender-4.2.15-windows-x64/blender.exe' --background --python tools/create-enemies.py
```

## Rigid-part contract

- Exactly five independently transformable mesh parts: Body, Head, Arms, LegL, LegR.
- Authoring axes are +Y up and +Z forward, with feet resting on Y=0.
- Origins: Body `[0, 0.48, 0]`; Head `[0, 0.94, 0.02]`; Arms `[0, 0.65, 0.02]`;
  LegL `[-0.105, 0.34, 0]`; LegR `[0.105, 0.34, 0]`.
- `spitter.glb`: 3920 hero triangles.
- `spitter-lod.glb`: 1126 LOD triangles.

Both GLBs use one soft-PBR atlas material with embedded 256x256 base-color and packed ORM
PNGs. Matching external PNG copies are retained under `textures/` for inspection and tooling.

The GLBs intentionally contain no exported animation clips. Gameplay motion is supplied by
procedural runtime animations over the five rigid parts. This model is original generated work;
`originalReferenceAvailable` is false because there is no source/reference character asset.
